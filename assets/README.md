# Assets

Portfolio media lives here, grouped by project or site section.

- `site-background.avif` and `site-covers/` shape the shared page atmosphere and archive heroes.
- Project folders such as `photo-diary/`, `playtestiq/`, `glorgo/`, `neuromancer/`, `open-your-browser/`, and `pacn/` hold case-study media.
- `design-gallery/` holds posters, portraits, esports graphics, semester dumps, and motion pieces.
- Top-level legacy files stay only when they are still referenced by `data.js`.

Keep new assets project-specific when possible, optimize large screenshots before committing, and remove files once they are no longer referenced.
